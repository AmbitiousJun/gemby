## 使用说明

1. 目前只适配 AndroidTV，同时尽量让平板/模拟器也能够正常使用，欢迎 issue 区反馈问题，佛系更新～
2. 任意界面（播放页除外）长按返回键可快速退回首页
3. 播放页中，方向键上 (↑)、下 (↓) 可调节相对音量
4. 播放页中，方向键左 (←)、右 (→) 可快速跳转播放位置
5. 播放页中，菜单键和确认 (OK) 键均可唤出控制器
6. 播放页中，双击 OK 键可快捷切换倍速（可在设置中自定义修改倍速值）
7. 播放页中，三击 OK 键可临时标记片头片尾（仅列表播放模式下生效）
8. 触摸屏长按、键盘 M 键、遥控器菜单键均可唤出卡片菜单
